# NewsHub — Plataforma Web de Noticias

Prototipo funcional de la Entrega 2 del módulo de Desarrollo Front-end (Politécnico Grancolombiano).

## Funcionalidades implementadas

- Renderizado dinámico de noticias a partir de datos locales (`js/data.js`).
- Filtro de noticias por categoría en el catálogo.
- Gestión de favoritos con `localStorage` (agregar, quitar, listar).
- Formulario de contacto con validación de campos obligatorios y formato de correo.
- Diseño responsivo (escritorio, tablet y móvil).
